# 4. Компоненты (Presentation Layer)

## 4.1 Карта компонентов

```
App
├── LoginPage                  (публичный маршрут)
└── PrivateRoute
    └── MainLayout
        ├── AppBar              (шапка, логаут, Ctrl+K)
        ├── ResizeHandle        (drag для изменения ширины)
        ├── Sidebar
        │   ├── SectionItem     (внутренний компонент)
        │   │   └── SubsectionItem (внутренний компонент)
        │   │       └── PageItem (ссылка на страницу)
        │   └── [Диалоги: создание раздела / подраздела / страницы]
        ├── PageView
        │   ├── MDXEditor       (режим редактирования)
        │   ├── MDXEditor readOnly (режим просмотра)
        │   │   └── MermaidBlockEditor → MermaidDiagram
        │   └── [Диалоги: удаление страницы]
        ├── EmptyState          (когда страница не выбрана)
        └── SearchDialog        (модальный поиск)
```

---

## 4.2 MainLayout (`MainLayout.jsx`)

**Ответственность:** корневая оболочка авторизованного приложения.

| Функция | Описание |
|---------|----------|
| Шапка (AppBar) | Название приложения, кнопка поиска (Ctrl+K), имя пользователя, кнопка выхода |
| Сайдбар | Постоянный на desktop, временный на mobile |
| ResizeHandle | Перетаскивание для изменения ширины сайдбара |
| URL-синхронизация | `useMatch` → парсинг slug → `cookbookStore.selectPage()` |
| Ошибки | Snackbar уведомление из `uiStore.error` |
| Поиск | Открывает `SearchDialog` по Ctrl+K / Cmd+K |

**Зависимости:** `cookbookStore`, `authStore`, `uiStore`

---

## 4.3 Sidebar (`Sidebar.jsx`)

**Ответственность:** навигационное дерево с поддержкой CRUD.

| Функция | Описание |
|---------|----------|
| Дерево навигации | Разделы → Подразделы → Страницы, expand/collapse |
| Ленивая загрузка | Подразделы и страницы загружаются при первом раскрытии |
| Контекстное меню | Редактировать / Удалить (только для `admin`) |
| Создание | Диалоги создания раздела, подраздела, страницы |
| Выделение | Подсвечивает текущую активную страницу |

**Внутренние компоненты:**
- `SectionItem` — один раздел с кнопкой раскрытия и контекстным меню
- `SubsectionItem` — один подраздел, содержит список страниц
- `PageItem` — ссылка на страницу (через `<Link>`)

**Зависимости:** `cookbookStore`, `authStore`

---

## 4.4 PageView (`PageView.jsx`)

**Ответственность:** просмотр и редактирование содержимого страницы.

| Функция | Описание |
|---------|----------|
| Режим просмотра | MDXEditor в режиме `readOnly`, полный рендеринг Markdown |
| Режим редактирования | MDXEditor с полным тулбаром |
| Mermaid | Кастомный дескриптор: textarea + превью в edit, только диаграмма в view |
| Редактирование заголовка | Inline-редактирование названия страницы |
| Сохранение | `cookbookStore.updatePage()` → автовыход из режима редактирования |
| Удаление | Диалог подтверждения → `cookbookStore.deletePage()` |

**Плагины MDXEditor:**

| Плагин | Назначение |
|--------|------------|
| `headingsPlugin` | H1–H6 |
| `listsPlugin` | Маркированные и нумерованные списки |
| `quotePlugin` | Цитаты |
| `tablePlugin` | Таблицы |
| `linkPlugin` + `linkDialogPlugin` | Ссылки с диалогом |
| `codeBlockPlugin` | Блоки кода, кастомный дескриптор для Mermaid |
| `codeMirrorPlugin` | Подсветка синтаксиса (JS, Bash, Java) |
| `diffSourcePlugin` | Переключение rich-text / markdown-source / diff |
| `markdownShortcutPlugin` | Горячие клавиши Markdown |
| `toolbarPlugin` | Тулбар с форматированием |

**Зависимости:** `cookbookStore`, `authStore`

---

## 4.5 SearchDialog (`SearchDialog.jsx`)

**Ответственность:** полнотекстовый поиск по всему контенту.

**Алгоритм поиска:**
1. Поиск по заголовкам страниц (приоритет 1)
2. Поиск по содержимому страниц (приоритет 2)
3. Поиск по названиям подразделов (приоритет 3)
4. Поиск по названиям разделов (приоритет 4)
5. Дедупликация результатов по `pageId`
6. Сортировка по приоритету

Результаты содержат сниппет (фрагмент совпавшего текста). Клик по результату закрывает диалог и навигирует к странице.

**Зависимости:** `cookbookStore`

---

## 4.6 LoginPage (`LoginPage.jsx`)

**Ответственность:** форма аутентификации.

- Форма: поля `username` и `password`
- Кнопка с индикатором загрузки во время запроса
- Отображение ошибки из `authStore.error`
- Редирект авторизованного пользователя на `/`

**Зависимости:** `authStore`

---

## 4.7 PrivateRoute (`PrivateRoute.jsx`)

**Ответственность:** защита маршрутов от неавторизованного доступа.

```
if (!authStore.initialized)  → Spinner (ждём инициализацию)
if (!authStore.isAuthenticated) → Navigate to /login
else → <Outlet /> (рендерим дочерний маршрут)
```

**Зависимости:** `authStore`

---

## 4.8 EmptyState (`EmptyState.jsx`)

**Ответственность:** контекстно-зависимые заглушки.

| Состояние | Отображение |
|-----------|-------------|
| Нет выбранной страницы | «Выберите страницу из меню слева» |
| Подраздел без страниц | «Подраздел пуст. Создайте первую страницу» + кнопка |
| Подраздел со страницами | Список страниц подраздела для быстрого перехода |

---

## 4.9 MermaidDiagram (`MermaidDiagram.jsx`)

**Ответственность:** рендеринг Mermaid-диаграммы в SVG.

- Инициализирует `mermaid` единожды при загрузке модуля
- Обновляет SVG при изменении `code`
- Отображает сообщение об ошибке, если синтаксис некорректен
- Уникальные ID через глобальный счётчик (предотвращает конфликты)

---

## 4.10 ResizeHandle (`ResizeHandle.jsx`)

**Ответственность:** drag-интерфейс для изменения ширины сайдбара.

- Обрабатывает `mousedown` → `mousemove` → `mouseup`
- Ширина зажата в диапазоне [200, 600] px
- Сохраняется через `uiStore.setSidebarWidth()` → `localStorage`
