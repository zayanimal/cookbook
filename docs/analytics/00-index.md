## Краткая аннотация

**Cookbook** — это SPA-приложение для ведения внутренней документации по инженерным системам дома. Система реализована на React 18 + MobX с трёхуровневой иерархией контента (Раздел → Подраздел → Страница). Контент хранится в формате Markdown с поддержкой диаграмм Mermaid.

Приложение поддерживает два режима работы:
- с реальным REST API (backend на порту 9000)
- с in-memory mock API для разработки без бэкенда

Разграничение доступа реализовано через JWT + ролевую модель (`admin` / `client`).
