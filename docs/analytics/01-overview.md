# 1. Обзор проекта

## 1.1 Назначение

**Cookbook** — веб-приложение для хранения и редактирования технической документации по инженерным системам дома. Предназначено для использования в частной сети (home engineering).

## 1.2 Функциональные требования

| ID | Требование |
|----|------------|
| FR-01 | Пользователь может авторизоваться по логину и паролю |
| FR-02 | Авторизованный пользователь просматривает иерархию: Раздел → Подраздел → Страница |
| FR-03 | Страница содержит контент в формате Markdown |
| FR-04 | Администратор может создавать, редактировать и удалять разделы, подразделы и страницы |
| FR-05 | Клиент имеет доступ только на чтение |
| FR-06 | Полнотекстовый поиск по заголовкам и содержимому страниц (Ctrl+K) |
| FR-07 | Поддержка диаграмм Mermaid внутри страниц |
| FR-08 | Приложение работает как PWA (offline-режим) |
| FR-09 | Боковая панель навигации изменяется по ширине (drag-resize) |
| FR-10 | URL отражает текущую выбранную страницу (deep linking) |

## 1.3 Нефункциональные требования

| ID | Требование |
|----|------------|
| NFR-01 | Адаптивная вёрстка: desktop (md+) и mobile |
| NFR-02 | Ленивая загрузка подразделов и страниц |
| NFR-03 | Персистентное хранение ширины сайдбара (localStorage) |
| NFR-04 | Токен сессии хранится в защищённых cookie (SameSite=strict, срок 7 дней) |
| NFR-05 | Поддержка работы без backend через mock API (VITE_USE_MOCKS) |

## 1.5 Конфигурация окружения

VITE_API_BASE_URL=http://cookbook:9000/api  # URL бэкенда
